## Формат данных

Предметная область — учебные аудитории. Модель `Auditorium` содержит обязательные поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `uid` | `str` | Непустой уникальный идентификатор в каталоге |
| `name` | `str` | Непустое название |
| `category` | `str` | Непустая категория |
| `date` | `str` | Год (`2026`) или дата вида `01.09.2026` |
| `number` | `int` | Положительный номер аудитории |
| `size` | `str` | Одно из значений `small`, `medium`, `large` |

При создании объекта Pydantic проверяет поля. Ошибка проверки преобразуется в `InvalidEntityError`
В текущем регулярном выражении для `date` разделители даты не ограничены точкой

Каталог сохраняется в JSON-объект с полями `format_version` и `container`. В `container` ключом служит `uid`, а значением — поля аудитории:

```json
{
  "format_version": 1,
  "container": {
    "101": {
      "uid": "101",
      "name": "Лекционная аудитория",
      "category": "лекционная",
      "date": "2026",
      "number": 101,
      "size": "medium"
    }
  }
}
```

## Возможности программы

1. Добавление, получение и удаление аудитории по идентификатору
2. Поиск по точному совпадению категории и по части названия без учёта регистра
3. Получение числа объектов, проверка наличия идентификатора и перебор аудиторий в лексикографическом порядке `uid`
4. Сохранение каталога в JSON и загрузка из JSON
5. Предметные исключения для некорректной сущности, дубликата идентификатора, отсутствующего объекта, ошибки структуры сохранённой сущности и повреждённого файла

---

## Как работает каталог

Модель `Auditorium` и класс `Catalog` находятся в `src/object_catalog/models.py`. Каталог хранит аудитории в словаре по `uid`. Методы поиска создают новые списки результатов, поэтому изменение списка не меняет состав каталога

Функции `catalog_save()` и `catalog_load()` находятся в `src/object_catalog/storage.py`. Сохранение записывает текущий состав каталога целиком. Для нового или повреждённого файла устанавливается `format_version: 1`. При перезаписи версия увеличивается, если оба каталога непусты и набор полей сущности отличается от сохранённого. При загрузке сначала создаётся новый каталог, и только после успешного разбора всех сущностей он возвращается вызывающему коду

Текущая загрузка не проверяет само значение `format_version`: `UnsupportedVersionError` возникает при ошибке создания сущности из сохранённых данных. Повреждённый JSON и отсутствие обязательного ключа `container` вызывают `CorruptedFileError`

## Обработка ошибок

В `src/object_catalog/errors.py` определён базовый `CatalogError` и его наследники:

| Исключение | Когда возникает |
| --- | --- |
| `InvalidEntityError` | Данные аудитории не прошли проверку при создании |
| `IdDuplicateError` | В каталог добавляют объект с существующим `uid` |
| `ObjectNotFoundError` | Запрошено получение или удаление отсутствующего `uid` |
| `UnsupportedVersionError` | При загрузке не удалось создать сущность из данных JSON |
| `CorruptedFileError` | Файл при загрузке отсутствует, содержит некорректный JSON или не содержит `container` |
